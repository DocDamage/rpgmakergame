# IMPLEMENTATION NOTES

1. **Audio:** Banter should be subtitled only (no VO) to reduce cost
2. **Interrupt:** Banter pauses if combat starts, resumes after if possible
3. **Priority:** Character-specific banter overrides generic banter
4. **Frequency:** Max 1 banter per 5 minutes of travel
5. **Conditions:** Some banter requires specific relationship levels
6. **Exclusions:** Dead/knocked out characters don't participate
