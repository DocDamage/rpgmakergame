# IMPLEMENTATION NOTES

1. **Priority Tiers:**
   - Critical: Progenitor Engine, Mercer, Alexander
   - High: Main characters, major bosses
   - Medium: Other bosses, elites
   - Low: Generic enemies (text only)

2. **Localization:** All combat text must be localization-friendly
3. **Subtitle timing:** Match VO length + 0.5s buffer
4. **Repetition protection:** Don't repeat same line within 3 battles
5. **Context awareness:** Some lines only play in specific areas/story points
