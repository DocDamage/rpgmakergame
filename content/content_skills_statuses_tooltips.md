**Type:** Support/Debuff  
**Cooldown:** 3 turns  
**Target:** Single enemy

# CRAFTING UI STRINGS

## Crafting Station: BLACKSMITH

### Success
```
「[Item Name] forged!」
Quality: [★★★☆☆]
Bonus stat: [+5 ATK]
```

### Failure
```
「The metal cracked.」
Materials lost: [X]
Skill check failed by: [Y]
```

### Requirements Not Met
```
「Not enough materials.」
Missing:
- Iron Ore ×[X]
- Coal ×[Y]

「Skill too low.」
Required: Blacksmithing [Level]
Current: [Level]
```

### Confirmation
```
「Forge [Item Name]?」
Materials required:
- Iron Ore ×3
- Leather ×2
- Coal ×1

「This will take [Time]. Continue?」
```
