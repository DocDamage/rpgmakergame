# Reusable Interior Templates

## Overview
7 base interior layouts that can be palette-swapped for all 13 towns.

## Template Checklist

### 1. Inn Interior (32x24)
- [ ] Base layout
- [ ] Desert variant (Dusthaven)
- [ ] Sanctuary variant (Ashveil)
- [ ] Swamp variant (Mirewatch)
- [ ] Port variant (Brinegate)
- [ ] Highland variant (Prismridge)
- [ ] Volcanic variant (Cinderstep)
- [ ] Northern variant (Gravemark, Rimehold)
- [ ] Chrono variant (Chronowake)

**Layout:** Counter, 3-4 tables, stairs to rooms (implied), warm lighting

### 2. Item Shop (32x24)
- [ ] Base layout
- [ ] Palette variants for each town

**Layout:** Counter, shelves, display tables, storage

### 3. Smith/Forge (32x24)
- [ ] Base layout
- [ ] Basic forge variant
- [ ] Master forge variant (Cinderstep)

**Layout:** Forge (center/back), anvil, weapon racks, counter

### 4. Residential House A (24x18)
- [ ] Base layout
- [ ] Palette variants

**Layout:** Main room, kitchen area, 1-2 bed spaces

### 5. Residential House B (24x18)
- [ ] Base layout
- [ ] Different arrangement for variety

**Layout:** Alternative arrangement of same elements

### 6. Town Hall / Hall (40x28)
- [ ] Base layout
- [ ] Sanctuary variant (Ashveil)
- [ ] Town Hall variant
- [ ] Command center variant

**Layout:** Open floor, central desk/altar, seating, impressive scale

### 7. Secret Room (24x18)
- [ ] Base layout
- [ ] Black market variant
- [ ] Resistance meeting variant

**Layout:** Cluttered, hidden entrance, suspicious atmosphere
