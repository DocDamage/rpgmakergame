## 1) Core Intent

1. **A city that "didn't fall"** — it's paused, edited, and hollowed by Time
2. **Multi-route dungeon-city** — no linear path; players unlock routes based on seated relics
3. **Scavenger Relay Camp** replaces normal shops — limited vendor/save node
4. **Relic-based gating** — each Foundation unlocks new traversal options

## 3) Relic-Based Gating System

| Relic | Unlock | Effect |
|-------|--------|--------|
| **Time (D7)** | Outer Wards + Archive District | Enter the city; time locks bypassed |
| **Mass (D6)** | Boulevard rubble gates | Clear collapsed blocks to reach boulevard sections |
| **Tide (D5)** | Underworks flood lanes | Open submerged passages |
| **Heat (D4)** | Optional shortcuts | "Ice-stasis burn-through" paths |
| **Light (D3)** | Hidden routes | Reveal "Crown Sigil" wall routes inside city |

## 10) Implementation Notes

1. **Atmosphere priority:** The city should feel "hollow" not "destroyed" — echoes, not explosions
2. **Relic gating:** Make each unlock feel significant; don't front-load everything
3. **The Crown Spire:** Always visible from multiple angles — the "mountain" players are climbing
4. **Dominion presence:** Bureaucratic, not military — seals, permits, paperwork walls
