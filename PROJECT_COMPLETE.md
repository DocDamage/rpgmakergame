3. Name it "Chroma's Edge"

### Step 2: Copy Assets
1. Open your project folder
2. **Copy** `C:/Users/Doc/Desktop/game/img/` → Your project `img/`
3. **Copy** `C:/Users/Doc/Desktop/game/audio/` → Your project `audio/`

### Step 3: Configure Database
1. Open Database (F9)
2. Import animations from `img/animations/` folders
3. Set up weapons with icons from `img/system/weapons/`
4. Configure battle backgrounds from `img/battlebacks1/`
