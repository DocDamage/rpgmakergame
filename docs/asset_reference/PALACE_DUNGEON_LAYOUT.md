# Palace Dungeon Layout
## Using Terranigma Loire Castle Components

The Palace is the final dungeon of Chroma's Edge. This document details the complete layout using extracted sections from Terranigma's Loire Castle.

---

## 🗺️ OVERVIEW

**Theme:** Corrupted royal palace, once majestic, now tainted by the Extinguisher's influence
**Tone:** Dark opulence, decaying grandeur, ominous
**Length:** 15-20 rooms, ~45 minutes to traverse
**Boss:** The Extinguisher (Final Boss)

---

## 📐 FLOOR PLAN

### FLOOR 1: The Fallen Entrance
```
┌─────────────────────────────────────┐
│  [Entrance] → [Grand Hall] → [East  │
│     ↑           ↓         Wing]    │
│  [West      [Stairwell]    (Shop)   │
│  Wing]        ↓                      │
│ (Lore)    [Storage]                  │
└─────────────────────────────────────┘
```

**Rooms:**
1. **Entrance Hall** - Former glory, now darkened
   - Asset: Loire Castle 1F - Entrance section
   - Enemies: Palace Guards (corrupted)
   
2. **Grand Hall** - Central hub
   - Asset: Loire Castle 1F - Main hall
   - Checkpoint/Save point
   
3. **West Wing (Library)** - Lore tablets
   - Asset: Loire Castle 1F - Library & Guest Room
   - Secret: Historical records of the Extinguisher
   
4. **East Wing (Merchant)** - Last shop before boss
   - Asset: Loire Castle 1F - Guest Room variant
   - NPC: Mysterious vendor (Twist's contact?)
   
5. **Storage Room** - Supplies, minor loot
   - Asset: Loire Castle 1F - Pantry section
   
6. **Stairwell** - To Floor 2
   - Asset: Loire Castle Tower base

**Rooms:**
7. **Armory** - Weapon racks, combat tutorial reminder
   - Asset: Loire Castle 2F - Equipment section
   - Loot: Best weapons in game (optional boss)
   
8. **Hall of Guards** - Elite enemy encounter
   - Asset: Loire Castle 2F - Guard stations
   - Puzzle: Disable alarm system
   
9. **Royal Lounge** - Restoration point
   - Asset: Loire Castle 2F - Lounges section
   - Safe room, full heal
   
10. **Throne Antechamber** - Pre-boss tension
    - Asset: Loire Castle 2F - Small throne room
    - Cutscene: The Extinguisher revealed
    
11. **THRONE ROOM** - Final Battle
    - Asset: Loire Castle 2F - Main Throne Room
    - **THE RED CARPET MOMENT**
    - Boss: The Extinguisher (3 phases)

## 🎭 STORY BEATS

### Entrance (Floor 1)
- Party arrives through broken main doors
- Kade: "This... this was my mother's palace."
- Environmental storytelling: Tapestries showing the Kingdom's fall

### Grand Hall (Floor 1)
- First encounter with Corrupted Guards
- Combat tutorial reminder: "Remember what you've learned"

### Library (Floor 1 - Optional)
- Twist discovers the truth about the Extinguisher
- Nix-7: "So... we're fighting a former Guardian?"

### Stairwell (Floor 1 → 2)
- Rising tension music
- Visual transition: More corruption, darker colors

### Hall of Guards (Floor 2)
- Mid-dungeon boss: Corrupted Captain
- Korr: "He was my mentor... I'll give him a warrior's death."

### Royal Lounge (Floor 2)
- Last safe point
- Party banter about their journey
- Optional: Rest and full heal

### Throne Antechamber (Floor 2)
- The Extinguisher speaks: "Welcome, children. I've been waiting."
- Renna: "You... you knew we were coming?"

### Throne Room (Floor 2 - FINAL)
- Three-phase boss battle
- **Phase 1:** The Extinguisher (humanoid form)
- **Phase 2:** Corruption Manifest (monster form)
- **Phase 3:** Chroma's Wrath (desperation)

### True Ending Path (Floor 3 - Optional)
- Requires all 12 shrines activated
- Reveals: The Extinguisher was trying to SAVE the world
- Choice: Destroy or Absorb the Extinguisher
