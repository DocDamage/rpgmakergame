## 🎮 RPG MAKER MZ SETUP

### Creating IconSet.png

RPG Maker MZ uses a single `img/system/IconSet.png` file with a 16x16 grid.

**Recommended Approach:**
1. Use **icons_full_16.png** as your base IconSet.png
2. Copy it to `img/system/IconSet.png`
3. Reference icons by index (0-1023)

### Icon Index Reference (icons_full_16.png)

| Row | Icons | Category |
|-----|-------|----------|
| 0-7 | 0-127 | Weapons (swords, axes, spears) |
| 8-15 | 128-255 | Armor (helms, body, shields) |
| 16-23 | 256-383 | Consumables (potions, food) |
| 24-31 | 384-511 | Materials (ores, gems, herbs) |
| 32-39 | 512-639 | Key Items (quests, maps) |
| 40-47 | 640-767 | Skills (physical, magic) |
| 48-55 | 768-895 | UI Elements (arrows, marks) |
| 56-63 | 896-1023 | Misc (blank, special) |

### Using 32x32 Icons for Skills

For skill icons in menus, you can:
1. Use **tf_icons_skills1_32x32.png** for physical skills
2. Use **tf_icons_skills2_32x32.png** for magic skills
3. Import as pictures and display in skill menu
