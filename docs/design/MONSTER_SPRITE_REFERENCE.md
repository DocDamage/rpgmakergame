## 🎨 SPRITE SPECIFICATIONS

### Standard Sizes:
| Type | Dimensions | Format | Notes |
|------|------------|--------|-------|
| Critter | 32x32 | PNG | Tiny enemies |
| Hunter | 64x64 | PNG | Standard combat |
| Predator | 96x96 | PNG | Large threats |
| Apex | 128x128 | PNG | Boss tier |
| Legendary | 256x256 | PNG | Unique bosses |

### Animation Frames:
| Animation | Frames | Notes |
|-----------|--------|-------|
| Idle | 2-4 | Breathing/floating |
| Attack | 3-6 | Strike motion |
| Hurt | 1-2 | Hit reaction |
| Death | 4-8 | Defeat sequence |
| Special | 4-12 | Unique abilities |

## 📊 SPRITE PROCESSING WORKFLOW

### Step 1: Extraction
```bash
# Extract from source sheets using coordinates
python scripts/extract_sprites.py --source ffvi_monsters.png --output enemies/
```

### Step 2: Cleanup
- Remove background (make transparent)
- Center the sprite
- Ensure consistent sizing

### Step 3: Color Adjustment
- Match to Time Fantasy palette
- Adjust saturation per zone guidelines
- Ensure readability at small sizes

### Step 4: Animation
- Create idle frames (2-4)
- Create attack frames (3-6)
- Test in engine

### Step 5: Organization
```
assets/enemies/
├── dustbelt/
├── uplands/
├── mire/
├── prism/
├── ember/
├── tide/
└── [etc]
```
