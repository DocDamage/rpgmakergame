## 🎭 NPC VARIATION RULES

1. **Color = Role Variant**
   - Red: Aggressive/combat roles
   - Blue: Merchant/service roles  
   - Green: Nature/outsider roles
   - Black/Gray: Shadow/mystery roles
   - White: Pristine/holy roles

2. **Multiple Instances**
   - Same sprite type = same "family/profession"
   - Different colors = different individuals
   - e.g., All "foodboys" are brothers, colors = different brothers

3. **Cross-Zone Travelers**
   - snakecharmer: Mire → Tide → Dustbelt (touring)
   - lucha: Ember → Capital (championship circuit)
   - ironchef: Universal (famous traveling cook)
