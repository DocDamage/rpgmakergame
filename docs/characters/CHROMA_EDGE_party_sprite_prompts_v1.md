# Chroma's Edge — Party Sprite Sheet Prompt Pack (v1)
Copy/paste one prompt per character into your image generator.
Tip: If your generator can’t obey multi-section layout, use the built-in fallback line at the bottom of each prompt and stitch in Aseprite.

## Kade — Sprite Sheet Prompt
```text
CHARACTER: Kade (28)
Role/Class vibe: Gunblade Specialist / Dragon-Born Cyborg
Visual design: horn-ridge nubs along the brow; faint scale plates at collarbone and forearms; slit pupils; subtle heat-sheen breath; sleek expensive cybernetics along spine/torso with faint teal glow; tactical duster coat high collar; armored chest harness; utility belt; fingerless gloves; rugged boots/greaves; accents deep crimson + bronze + teal glow.
Overworld weapon pose: gunblade holstered or sheathed
Battle weapon pose: gunblade drawn (matte black with red core accents)

Create a single PNG sprite sheet with a transparent background, crisp 16-bit JRPG pixel art (SNES/PS1-era), no anti-aliasing, no blur, no text, no watermark, and perfect grid alignment. Keep silhouettes readable and consistent palette across sections.

SHEET LAYOUT (exact)
Section A — Overworld sprites (top-left):
- Frame size: 32×48 px each
- Grid: 4 rows × 4 columns = 16 frames
- Rows (top to bottom): DOWN, LEFT, RIGHT, UP
- Columns (left to right): IDLE, WALK1, WALK2, WALK3
- Overworld weapon is holstered/slung (non-threatening travel pose)

Section B — Portraits (below overworld):
- 5 portraits, each 128×128 px, bust/face
- One row, left to right, expressions:
  1) Neutral
  2) Smirk / confident
  3) Angry / intense
  4) Concerned / soft
  5) Determined / leader
- Transparent background, clean readable lighting

Section C — Battle sprites (right side):
- Side-view JRPG battle style, facing right
- 2 frames, each 128×128 px: IDLE1, IDLE2 (breathing loop)
- Battle weapon is drawn/ready

SPACING / EXPORT RULES
- Use 2 px padding between frames and between sections.
- Everything aligned to a pixel grid; no cropped pixels; no overlapping frames.

NEGATIVE / AVOID:
realistic rendering, painterly style, smooth gradients, blurry pixels, thick cartoony outlines, extra limbs, extra frames, text labels, backgrounds/scenes, UI elements.

Fallback if the tool struggles with the combined sheet: generate three separate transparent PNGs (Overworld grid only; 5 portraits row only; 2-frame battle idle only) using the exact same character design and palette.
```
