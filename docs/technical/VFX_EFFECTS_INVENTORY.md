## 📋 IMPLEMENTATION GUIDE

### For RPG Maker MZ:

**Step 1: Install Animations**
1. Extract animation ZIPs
2. Import to `img/animations/`
3. Create animation entries in Database > Animations
4. Assign to skills/items

**Step 2: Configure Skills**
```
Skill: Fireball
- Animation: Fire Mage - Fireball
- Damage: Fire element
- Effect: Burn status
```

**Step 3: Weapon Icons**
1. Extract weapon sprites
2. Add to iconset or use as pictures
3. Assign to weapons in database
