## D) Pedestal Hover / Inspect Panel (Right Panel)

| Field | Description |
|-------|-------------|
| **NAME** | Weapon name |
| **TYPE** | Weapon class (Blade, Spear, Whip, Bow, etc.) |
| **RESONANCE** | Foundation / Composite affinity |
| **ACCORD TRAIT** | Unique passive ability |
| **SIGNATURE BONUS** | What the weapon excels at |
| **BINDING** | Equip restrictions (if any) |

### Example Lines

```
Resonance: Shadow
Accord Trait: "When you Shadowwalk/Phase, gain Ward for 2 turns."
Signature Bonus: High crit windows, ambush control
Binding: Any wielder of Shadow-class weapons
```
