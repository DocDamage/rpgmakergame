## Implementation Notes
- Heroes99 is a layered animation atlas, not native RPG Maker 3x4 walk sheets.
- This pass synthesizes MZ walk rows from compatible atlas poses:
  - Down, Right, Up sampled from selected atlas rows.
  - Left generated by mirroring Right.
- Sheet format per actor: `$` single-character sheet (`144x256`, 3 columns x 4 rows, `48x64` frames).
